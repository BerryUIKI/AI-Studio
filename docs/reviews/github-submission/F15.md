## User impact

Active work can be interrupted after a graceful-shutdown refusal; closing can stop a pre-existing backend or defeat the promised exit policy.

## Proposed approach

Define explicit keep-running/stop-owned/force modes, respect refusals, wait for acknowledged safe shutdown, and never shut down an unowned service. Test titlebar close, Alt+F4, destroy, and active tasks.

## Acceptance criteria

- [ ] Keep Running preserves the intended backend/engine processes.
- [ ] A graceful shutdown refusal cannot lead to an implicit forced kill.
- [ ] An unowned/pre-existing backend is never shut down by window cleanup.
- [ ] Titlebar close, Alt+F4, window destruction, and active tasks obey the same explicit policy.
