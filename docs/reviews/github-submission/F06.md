## Summary

The mask canvas paints opaque white over an otherwise transparent mask. [macro_compiler.py:221](https://github.com/BerryUIKI/AI-Studio/blob/c1c5dbeaace01fc5e3fa68d8e3ebf410583b775b/backend/app/runners/macro_compiler.py#L221) uses `LoadImage`'s MASK output, which ComfyUI computes as `1 - alpha`. Painted pixels therefore become zero in that mask while unpainted transparent pixels become one. [ComfyUI LoadImage implementation](https://github.com/Comfy-Org/ComfyUI/blob/master/nodes.py).

## User impact

The area the user marks for editing can be protected while the surrounding area is selected. WebUI's grayscale mask and OpenAI's alpha conventions also require explicit adapters.

## Proposed approach
