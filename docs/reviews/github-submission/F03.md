## Reproduction or validation

On Windows, run an isolated Python process and pass os.getpid() to ComfySupervisor._verify_process_identity and WebUISupervisor._verify_process_identity. Both returned True for the unrelated probe process. Do not call stop or taskkill during this validation; no real process was terminated by the probe.

## User impact

A stale PID file can cause Berry to stop an unrelated Python process and its children, contrary to the external-process ownership requirement.

## Proposed approach

Verify executable path, command line/runtime identity, creation time, and ownership metadata before any termination; treat ambiguity as unowned. Test recycled PIDs without killing a real process.

## Acceptance criteria

- [ ] Verify executable/runtime path, process creation time, command line, and ownership before termination.
- [ ] A recycled or ambiguous PID is treated as unowned.
- [ ] Stopping an owned engine does not affect external engines or unrelated Python processes.
- [ ] Tests simulate stale PID files without terminating real processes.
